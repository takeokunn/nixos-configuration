#+STARTUP: content
* First Installation (X13Gen2)

X13Gen2 boots through Secure Boot (lanzaboote), unlocks LUKS with the TPM plus a PIN, and recreates ~/~ and ~/home~ on every boot; only ~/persist~, ~/nix~ and ~/var/log~ survive.

** Before You Start

On the current system:

1. Apply firmware and Secure Boot database (dbx) updates with ~fwupdmgr update~. The TPM unlock is bound to PCR 7, which these updates change, so they must happen before the TPM is enrolled.
2. Copy everything you want to keep out of the machine. The install erases the disk.

Boot the NixOS installer USB, open a shell with ~nix-shell -p nvme-cli~, and erase the drive:

3. Check whether the NVMe drive offers a 4096-byte LBA format:
   #+begin_src shell
     sudo nvme id-ns -H /dev/nvme0n1 | grep "LBA Format"
   #+end_src
   If a 4096-byte format is listed, switch to it and erase the drive with ~sudo nvme format /dev/nvme0n1 --lbaf=<index> --ses=1~. Otherwise erase it with ~sudo nvme sanitize /dev/nvme0n1 --sanact=2~.

In the firmware setup:

4. Clear the TPM so nothing from the old install stays enrolled, and put Secure Boot into Setup Mode.

nixos-anywhere installs from GitHub, so the main branch must already contain ~secrets/x13gen2.yaml~ (see [[*Secrets][Secrets]]) and ~hosts/X13Gen2/u2f-keys~ (see [[*YubiKey][YubiKey]]). Push any change to them before installing.

** Install with nixos-anywhere

Boot the NixOS installer USB on the target, connect to the network (~nmtui~), set a password for the ~nixos~ user with ~passwd~, and note the address from ~ip addr~.

On the Mac, which holds the pass store, restore the SSH host key into a staging directory and install. Run this in bash, not fish. The host key must be placed before the first boot because sops derives its decryption key from it.

#+begin_src bash
  stage=$(mktemp -d)
  install -d -m 755 "$stage/persist/etc/ssh"
  pass show x13gen2/ssh_host_ed25519_key > "$stage/persist/etc/ssh/ssh_host_ed25519_key"
  pass show x13gen2/ssh_host_ed25519_key.pub > "$stage/persist/etc/ssh/ssh_host_ed25519_key.pub"
  chmod 600 "$stage/persist/etc/ssh/ssh_host_ed25519_key"

  # A temporary passphrase; it is removed after the TPM and recovery key are enrolled.
  read -s -p "Temporary LUKS passphrase: " LUKS_PASS

  nix run github:nix-community/nixos-anywhere -- \
    --flake github:takeokunn/nixos-configuration#X13Gen2 \
    --extra-files "$stage" \
    --disk-encryption-keys /tmp/luks-password <(printf '%s' "$LUKS_PASS") \
    nixos@<TARGET_IP>

  unset LUKS_PASS
  rm -rf "$stage"
#+end_src

** First Boot

Until step 3 is done, every boot asks for the temporary passphrase.

1. On the first boot, lanzaboote generates Secure Boot keys in ~/var/lib/sbctl~, enrolls them and reboots.
2. After that reboot, check that Secure Boot is on. If it reports disabled, enable Secure Boot in the firmware setup.
   #+begin_src shell
     bootctl status | grep "Secure Boot"
   #+end_src
3. Enroll the TPM with a PIN and a recovery key, then remove the temporary passphrase:
   #+begin_src shell
     sudo systemd-cryptenroll /dev/disk/by-partlabel/cryptroot --tpm2-device=auto --tpm2-pcrs=7 --tpm2-with-pin=yes
     sudo systemd-cryptenroll /dev/disk/by-partlabel/cryptroot --recovery-key
     sudo systemd-cryptenroll /dev/disk/by-partlabel/cryptroot --wipe-slot=password
   #+end_src
   Store the printed recovery key in pass on the Mac. When a firmware update changes PCR 7, the TPM no longer unlocks the disk: unlock with the recovery key, then enroll the TPM again:
   #+begin_src shell
     sudo systemd-cryptenroll /dev/disk/by-partlabel/cryptroot --wipe-slot=tpm2 --tpm2-device=auto --tpm2-pcrs=7 --tpm2-with-pin=yes
   #+end_src
4. Join the tailnet: ~sudo tailscale up~.

** Secrets

~secrets/x13gen2.yaml~ is encrypted for two age recipients listed in [[file:../.sops.yaml][.sops.yaml]]: the editing key on the Mac (~~/.config/sops/age/keys.txt~) and the key derived from this machine's SSH host key. It holds:

- ~networkmanager-env~: ~HOME_WIFI_SSID=...~ and ~HOME_WIFI_PSK=...~ lines, read by NetworkManager's ~ensureProfiles~.
- ~take-hashed-password~: a yescrypt hash (~mkpasswd --method=yescrypt~) for the login, greeter and sudo password.

Edit it on the Mac with ~sops secrets/x13gen2.yaml~.

If the host key in pass is lost, generate a new one, replace the ~x13gen2~ recipient in ~.sops.yaml~ with the output of ~ssh-to-age < ssh_host_ed25519_key.pub~, run ~sops updatekeys secrets/x13gen2.yaml~, and store the new key in pass.

** YubiKey

sudo, the greeter and the lock screen accept a YubiKey touch and fall back to the password. Register a key from the repository root on any machine with the key plugged in:

#+begin_src shell
  nix shell nixpkgs#pam_u2f -c pamu2fcfg -u take -o pam://X13Gen2 -i pam://X13Gen2 > hosts/X13Gen2/u2f-keys
#+end_src

~>~ replaces the registered keys. To add a second key, run ~pamu2fcfg -n -o pam://X13Gen2 -i pam://X13Gen2 >> hosts/X13Gen2/u2f-keys~ instead.

USBGuard blocks every USB device that no rule in [[file:../nixos/config/security.nix][nixos/config/security.nix]] allows; Yubico devices, hubs and internal ports are allowed. List blocked devices with ~sudo usbguard list-devices --blocked~ and allow one until it is unplugged with ~sudo usbguard allow-device <id>~. Add a rule to allow it permanently.

** Update Configuration

From a clone of this repository:

#+begin_src shell
  sudo nixos-rebuild switch --flake .#X13Gen2
#+end_src

The ~rescue~ boot entry starts the same system without the ~/etc~ overlay and USBGuard, for recovering when either of them breaks boot or blocks a needed device.

** Notes

- Old roots are kept for 7 days in ~/.btrfs/@old_roots~ ([[file:../hosts/X13Gen2/impermanence.nix][hosts/X13Gen2/impermanence.nix]]). Persisted paths are listed there and in [[file:../home-manager/wayland/impermanence/default.nix][home-manager/wayland/impermanence/default.nix]].
- btrbk snapshots ~@persist~ hourly into ~@snapshots~ (~/.btrfs/@snapshots~); container images live in ~@containers~ and are not snapshotted.
- DNS goes to Quad9 over TLS. On a captive portal, find the Wi-Fi link with ~resolvectl status~ and run ~resolvectl dnsovertls <link> no~ until signed in.

#+STARTUP: fold
* 初回インストール (M4-Max)

M4-Max は nix-darwin で管理する Mac (M4 Max) です。home-manager、Homebrew、mac-app-util を組み合わせています。

** 前提

- macOS (Apple Silicon)
- macOS のユーザー名が ~take~ であること
- Homebrew (https://brew.sh)。nix-darwin は Homebrew 本体をインストールしません。

** 手順 1: Xcode Command Line Tools を入れる

#+begin_src shell
  xcode-select --install
#+end_src

** 手順 2: Nix を入れる

公式のインストーラーを使います。

#+begin_src shell
  sh <(curl -L https://nixos.org/nix/install)
#+end_src

install.determinate.systems のインストーラーは既定で Determinate Nix を入れます。この設定では nix-darwin が Nix を管理していて、Determinate Nix を検出すると適用を中止するため、使いません。

** 手順 3: 設定を clone する

#+begin_src shell
  git clone https://github.com/takeokunn/nixos-configuration
  cd nixos-configuration
#+end_src

** 手順 4: nix-darwin を初めて適用する

#+begin_src shell
  sudo -H nix run nix-darwin --extra-experimental-features 'flakes nix-command' -- switch --flake .#M4-Max --show-trace
#+end_src

** 手順 5: ターミナルを開き直す

環境変数をすべて読み込むために、ターミナルを閉じて開き直します。

あとで設定を変えたときは、手順 4 のコマンドをもう一度実行します。

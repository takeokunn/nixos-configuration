#+STARTUP: fold
* 初回インストール (M4-Max)

M4-Max は nix-darwin で管理する Mac (M4 Max) です。

** 前提

- macOS (Apple Silicon)。macOS のユーザー名が ~take~ であること。
- nix-darwin は適用のたびに Homebrew のパッケージを [[file:../nix-darwin/config/homebrew.nix][nix-darwin/config/homebrew.nix]] に合わせ、書かれていないものを削除します。すでに Homebrew で入れたものを残したい場合は、手順 4 の前にこのファイルに追加します。

** 手順 1: Homebrew を入れる

https://brew.sh のインストーラーを実行します。nix-darwin は Homebrew 本体をインストールしません。Homebrew のインストーラーは、Xcode Command Line Tools がなければ一緒に入れます。

** 手順 2: Nix を入れる

公式のインストーラーを使います。

#+begin_src shell
  sh <(curl -L https://nixos.org/nix/install)
#+end_src

install.determinate.systems のインストーラーは使いません。このインストーラーは既定で Determinate Nix を入れますが、この設定では nix-darwin が Nix を管理していて、Determinate Nix を検出すると適用を中止します。

インストールが終わったら、~nix~ を PATH に入れるために、ターミナルを閉じて開き直します。

** 手順 3: 設定を clone する

#+begin_src shell
  git clone https://github.com/takeokunn/nixos-configuration
  cd nixos-configuration
#+end_src

** 手順 4: nix-darwin を初めて適用する

#+begin_src shell
  sudo -H nix run nix-darwin --extra-experimental-features 'flakes nix-command' -- switch --flake .#M4-Max --show-trace
#+end_src

** 手順 5: ターミナルを開き直す

環境変数をすべて読み込むために、ターミナルを閉じて開き直します。

** 設定を更新する

設定を変えたときは、clone したディレクトリで手順 4 のコマンドをもう一度実行します。
